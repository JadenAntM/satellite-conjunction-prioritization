# Dataset attribution

This project uses **Collision Avoidance Challenge — Dataset**, distributed by the European Space Agency's Space Debris Office at [Zenodo record 4463683](https://zenodo.org/records/4463683) under [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).

The release contains anonymized conjunction data messages received by ESA from 2015–2019. ESA credits the US Space Surveillance Network for the surveillance data supporting the release. The official source is downloaded separately; this repository does not redistribute its archive.

Project processing changes the release into cutoff-specific event rows, uses a strict pre-TCA final-message threshold label, and adds causal history summaries and conservative evaluation groups. These transformations are project analysis and are not an ESA endorsement or an operational certification.

Related dataset/task publication: [Uriot et al.](https://arxiv.org/abs/2008.03069). Existing sequence research: [Pinto et al.](https://arxiv.org/abs/2012.12450).

The dataset licence applies to the source data. This notice does not assign a separate licence to the project code.
